Username Checker.

Check a name against the length and character rules of 32 platforms, and open each profile in one tap. Free, no sign-up.

Platforms

Name variants

When your main name is taken, try one of these. Select one to check it.

How to use the username checker

  1. Type the name you want, without the @ sign.
  2. Check the rule badge on each platform. Green means the name fits the listed limits.
  3. Press "Open profile page" to see the platform. A not-found page usually means the name is free.
  4. If it is taken, try a variant, then sign up quickly on the platforms that matter most to you.

Platforms change their rules and their sign-up checks without notice. Confirm the name on the platform before you rely on it.

// questions/

Questions.

Is this username checker free?

Yes. It is free, needs no account, and you can use it as often as you like.

Does it tell me whether a username is taken?

No, not for certain. Platforms don't offer a reliable public check that browsers can use, so this tool gives you a direct link to each profile. If the page shows an empty profile or a not-found message, the name is probably free. Check the platform itself before you rely on it.

What do the rule badges mean?

A green badge means the name fits the length and character rules we list for that platform. A red badge means it breaks one of them. A grey badge means we don't list a rule for that platform, so check it on the site. Platforms can change their rules at any time.

Why does it show a limit for some platforms but not others?

We only list the length and character rules we are confident about. For the rest, the badge says no rule is listed, so you should check the platform's sign-up page.

Can I check a domain name here?

Not yet. Checking whether a domain is registered needs a lookup service, which this page does not use. We may add it later.

Is my search stored?

Recent searches are kept only in your browser on this device, and you can clear them at any time. We do not store your searches on our servers.

Why do the variants matter?

Many people add an underscore, a dot or a word such as official to a name that is already taken. Using the same base name everywhere makes you easier to find, so try the variants when the main name is taken.

Your privacy

This checker runs in your browser. Your recent searches are kept only on this device, and nothing you type is sent to our servers. Read the website privacy policy for details.
