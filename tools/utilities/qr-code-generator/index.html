QR Code Generator.

Turn a link or text into a QR code. Pick the size and colours, then download it as a PNG. Nothing you type is uploaded.

Higher error correction still scans if part of the code is damaged, but the code gets denser. Use Medium unless you plan to print it on something rough.

// about/

About this tool.

A QR code stores your text so a phone camera can read it. Most people use one to open a link, but it also works for Wi-Fi details, contact text, or a short note.

The code is drawn in your browser. Nothing you type or download is sent to our servers.

// faq/

Questions.

Is this QR code generator free?

Yes. There is no sign-up, no watermark, and no limit on how many codes you make.

Do the codes expire?

No. The code stores the text itself, not a link to our site, so it keeps working as long as the link or text is valid.

What size should I download for printing?

Choose 1024 px for posters or cards. Keep the code at least 2 cm wide when printed, and leave a blank margin around it.

Your privacy

This tool runs in your browser. The text you enter is not sent to our servers, and we do not ask for an account. Read the privacy policies for details.
