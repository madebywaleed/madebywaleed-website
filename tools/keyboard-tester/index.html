Press and hold as many keys as you can, for example A S D F J K L together. If some keys don't light up while others are held, the keyboard can't register that many at once (ghosting). Many keyboards stop at 6 keys plus modifiers.

Double-press check

0suspicious presses
None found. Tap each key normally a few times.

A worn switch can register one tap as two presses. Any press that starts within this window after the same key was released is flagged, because fingers can't tap that fast.

Polling rate estimate

–Hz

Press start, then roll your fingers quickly across as many keys as you can. The shortest gap between key events shows how often the keyboard reports to the computer. A browser can only tell rates up to about 2000 Hz apart, so 4000 and 8000 Hz keyboards will read as 1000 or 2000 Hz. If the result looks low, run it again and roll faster.

Capture every key

Some keys, like Esc, Windows/Command, Alt+Tab or F11, are normally used by the browser or the computer. Full-screen capture lets this page receive them (works in Chrome and Edge). Hold Esc for a couple of seconds to leave.

  • Fn is handled inside the keyboard and is never sent to the computer, so no website can test it. Test it by using it, for example Fn + a brightness key.
  • Print Screen and some laptop special keys may be taken by the computer before the browser sees them.
  • On a phone or tablet, connect a physical keyboard first.
  • Nothing you type is saved or sent anywhere.
